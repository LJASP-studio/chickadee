# Decisions

## 2026-02-02 Read tide times off the harbour's web page

The harbour publishes the day's tides on its web page; the tool reads them from there. No API key, no extra source.

## 2026-02-16 Read a public tide table instead

The harbour page's layout changed twice in two weeks and broke the reader both times. The tool reads the national public tide table instead, which has a fixed format. Replaces the decision of 2026-02-02.
